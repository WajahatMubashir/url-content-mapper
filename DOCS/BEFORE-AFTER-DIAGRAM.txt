│                    🔴 BEFORE (v1.2) - BROKEN                           │
└────────────────────────────────────────────────────────────────────────┘

Timeline when user visits homepage:

  1. Browser starts loading page
     │
  2. HTML <head> parsed
     │
  3. GA4/GTM script loads and executes
     │
     ├─> GA4 fires page_view event
     │   └─> content_category: undefined → "(not set)" ❌
     │
  4. Page body loads
     │
  5. DOM fully loaded
     │
  6. DOMContentLoaded event fires
     │
  7. Plugin script FINALLY executes (TOO LATE!)
     │
     └─> dataLayer.push({content_category: "homepage"})
         (But GA4 already sent the event!) ❌

  Result: "(not set)" in GA4 reports for 33,000+ sessions ❌

┌────────────────────────────────────────────────────────────────────────┐
│                    ✅ AFTER (v1.3) - FIXED                             │
└────────────────────────────────────────────────────────────────────────┘

Timeline when user visits homepage:

  1. Browser starts loading page
     │
  2. HTML <head> parsed
     │
  3. Plugin script loads and executes IMMEDIATELY ✅
     │
     └─> dataLayer.push({content_category: "homepage"})
         (Sets it RIGHT AWAY!) ✅
     │
  4. GA4/GTM script loads and executes
     │
     ├─> Reads dataLayer (content_category already there!) ✅
     │
     └─> GA4 fires page_view event with content_category ✅
     │
  5. Page body loads
     │
  6. DOM fully loaded
     │
  7. User sees page

  Result: Correct "homepage" category in GA4 reports ✅


Script Location (v1.3):
  <html>
    <head>
      <script src="...urlcoma-frontend-script.js"></script>
      <script>                           ← CORRECT POSITION (head)
        (function(){
          'use strict';
          window.dataLayer = window.dataLayer || [];
          // Executes IMMEDIATELY         ← CORRECT TIMING
          // No DOMContentLoaded wrapper! ← KEY FIX
          if (pathname === '/') {
            window.dataLayer.push({content_category: 'homepage'});
          }
        })();
      </script>

      ... GA4/GTM loads AFTER plugin ...  ← CORRECT ORDER
    </head>
    <body>
      ... page content ...
    </body>
  </html>


Console Output (v1.3):
  window.dataLayer
  → [{content_category: "homepage"}, ...GA4 events...]
  → content_category is FIRST! ✅


GA4 Event (v1.3):
  page_view {
    page_location: "https://yoursite.com/",
    page_title: "Homepage",
    content_category: "homepage"  ✅
  }
